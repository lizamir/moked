# MCP: שקע אחיד לכלים

## מה זה MCP
MCP הם ראשי התיבות של Model Context Protocol. זהו תקן פתוח שחברת Anthropic פרסמה בנובמבר 2024, והוא קובע דרך אחידה לחבר מודלי שפה לכלים ולמקורות מידע. הדימוי המקובל הוא שקע USB: במקום לבנות חיבור מיוחד לכל אפליקציה, בונים פעם אחת לפי התקן, וכל אפליקציה שתומכת בו יכולה להתחבר.

## שרת ולקוח
ב-MCP יש שני צדדים. השרת הוא תוכנה קטנה שמציעה יכולות, למשל חיפוש במאגר מסמכים. הלקוח הוא האפליקציה שבה יושב המודל, למשל Claude Desktop, והיא מתחברת לשרת ומשתמשת ביכולות שלו. שרת אחד יכול לשרת הרבה לקוחות שונים.

## מה שרת יכול להציע
שרת MCP יכול להציע שלושה סוגי דברים. כלים: פעולות שהמודל מבקש להפעיל. משאבים: מידע לקריאה, כמו קבצים או רשומות. תבניות: פרומפטים מוכנים מראש שהמשתמש יכול לבחור.

## בטיחות
שרת MCP רואה את כל מה שנשלח אליו, ויכול להחזיר למודל כל טקסט. לכן מתקינים רק שרתים ממקור שסומכים עליו, קוראים אילו הרשאות הוא מבקש, ולא מחברים שרת לא מוכר לחשבון שיש בו מידע רגיש.
