# API ו-Webhooks

## זמינות ומפתחות
ה-API זמין במסלול העסקי בלבד. מפתחות API יוצרים במסך הגדרות > מפתחים. מפתח מוצג פעם אחת בלבד בזמן היצירה.

## מגבלת קצב
מותר לשלוח עד 120 בקשות בדקה לכל מפתח. חריגה מהמגבלה מחזירה קוד 429 עם כותרת Retry-After שמציינת כמה שניות להמתין.

## Webhooks
אפשר להירשם לאירועים appointment.created ו-appointment.cancelled. אם השרת שלכם לא מחזיר תשובת 2xx, תורן מנסה שוב עד 5 פעמים עם השהיה הולכת וגדלה.

## אימות חתימה
כל קריאת webhook חתומה ב-HMAC-SHA256. החתימה נשלחת בכותרת X-Toran-Signature ויש לאמת אותה מול הסוד של ה-webhook.
